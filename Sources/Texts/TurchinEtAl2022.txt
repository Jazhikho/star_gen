## Abstract
*(Not extracted — PDF not acquired. Abstract from published paper.)*
Using the Seshat: Global History Databank, this study tests which of three theories best
explains the evolution of social complexity over 10,000 years of history across ~300
polities spanning 30 geographic regions. The three competing theories examined are:
(1) military competition (warfare drives social complexity), (2) ecological productivity
(agricultural surplus enables state formation), and (3) information transmission (writing,
measurement, and bureaucratic capacity). Key finding: warfare and agriculture are the
strongest empirical predictors of sociopolitical complexity across world history.
Bayesian model comparison and structural equation modeling are used for testing.

## Major claims, findings, models, assumptions, and limitations
- **Warfare is a primary driver of social complexity:** Military competition selects for
  larger, more organized polities with greater administrative capacity. This is the
  "cultural group selection" or "competitive exclusion" mechanism.
- **Agriculture enables social complexity but does not cause it alone:** Food surplus is
  a necessary but not sufficient precondition; it provides the resource base for
  specialists, armies, and administrations. Ecological productivity is a strong predictor
  only when combined with military competition.
- **Information transmission matters but is secondary:** Writing and measurement
  technologies are strong predictors of administrative complexity, but the causal direction
  is unclear — they may be symptoms rather than causes of rising complexity.
- **Seshat: Global History Databank:** The empirical foundation is 300+ polities across
  30 geographic regions, covering Neolithic to early modern period. Uses standardized
  social complexity scores.
- **Connects to TurchinEtAl2021WarMachines:** The war machines paper covers military
  technology; this paper covers the social complexity that warfare both produces and
  requires. Together they form a comprehensive account of how military competition
  drives civilizational development.
- **Limitation:** Pre-industrial dataset; modern warfare dynamics may differ significantly.
- **Limitation:** Seshat coding involves expert judgment; some regions and periods are
  data-sparse.
- **Limitation:** Causal direction is debated; this paper uses cross-lagged Bayesian
  methods but cannot fully resolve causality in historical data.

## Parameters, constraints, and mechanics implications

**Social complexity growth model (Turchin et al. 2022):**
```csharp
// Social complexity driven by: military competition + agricultural surplus
// Per Turchin 2022: these are the strongest predictors across 10,000 years

double militaryPressure = CountBorderConflicts(civilization) * conflictIntensity;
double agriculturalSurplus = civilization.FoodProductionIndex - civilization.PopulationDemand;

// Social complexity index (maps approximately to StarGen's GovernmentType + LawLevel)
double complexityGrowthRate = 0.0;
if (agriculturalSurplus > 0)
{
    complexityGrowthRate += agriculturalSurplus * 0.01;  // surplus enables growth
    complexityGrowthRate += militaryPressure * 0.03;     // competition accelerates it
}
// Information transmission (TechLevel ≥ 3 → writing available)
if (civilization.TechLevel >= 3)
{
    complexityGrowthRate *= 1.2;  // writing amplifies complexity accumulation
}
civilization.SocialComplexityIndex += complexityGrowthRate;
```

**Warfare as LawLevel accelerant:**
```csharp
// External military threat increases internal social cohesion and LawLevel
// Turchin 2022: competition → complexity → more laws, more bureaucracy
if (civilization.ActiveBorderConflicts > 0)
{
    civilization.LawLevel = Math.Min(
        civilization.LawLevel + 1,
        civilization.MaxLawLevel  // capped by administrative capacity
    );
}
```

**Agricultural productivity gate:**
```csharp
// State formation requires agricultural surplus (Turchin 2022; MaysharMoavPascali2022)
bool canFormState = civilization.FoodProductionIndex > civilization.SubsistenceThreshold;
if (!canFormState)
{
```
