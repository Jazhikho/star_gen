## Abstract
This is the sixth paper in the C-MetaLL (Cepheid Metallicity in the Leavitt Law) survey
series. The paper presents high-resolution spectroscopic analysis of 180 classical
Cepheid variable stars (DCEPs) observed with multiple spectrographs, based on 331
spectra. The analysis yields detailed abundance measurements for 29 chemical species
(Fe, alpha elements including Mg, Si, Ca, Ti; iron-peak elements; s-process elements
Y, Ba, La, Nd) in a sample spanning Galactocentric radii from 5 to 20 kpc. The primary
result is a set of radial abundance gradients for all 29 elements across the Milky Way
disk. The [Fe/H] gradient is measured as −0.071 ± 0.003 dex/kpc, consistent with
APOGEE-based measurements. The paper extends previous C-MetaLL work by adding
coverage of the metal-poor end ([Fe/H] < −0.4 dex), previously sparse in the literature.
Classical Cepheids are young-to-intermediate-age stars (~50 Myr–1 Gyr), providing a
tracer complementary to APOGEE giant stars.

## Major claims, findings, models, assumptions, and limitations
- [Fe/H] radial gradient: −0.071 ± 0.003 dex/kpc over 5–20 kpc (the widest baseline
  for Cepheid-based gradient measurements in the C-MetaLL series to this date)
- Coverage of the metal-poor outer disk: Cepheids at R > 14 kpc with [Fe/H] < −0.4 dex
  are included, extending the range of known disk metallicities
- Alpha-element gradients ([Mg/Fe], [Ca/Fe], etc.) measured for the first time at
  high precision across this spatial range using Cepheids
- s-process element gradients (Y, Ba, La, Nd) also measured, providing nucleosynthetic
  context for the gradient
- Cepheids as young tracers: represent the current ISM metallicity distribution, unlike
  APOGEE giants which carry the metallicity of their birth location + age effects
- Consistent with APOGEE: −0.071 vs −0.066 dex/kpc — two independent methods agree
  within ~0.5 σ, strongly confirming the gradient value
- Limitation: Cepheids are distance-limited (brighter = farther; faint end inaccessible
  without larger telescopes); sample may be incomplete below ~10 kpc at extreme radii
- Limitation: ~50 Myr–1 Gyr age range means Cepheids cannot trace ancient enrichment
  history (only recent ISM abundance); complement with APOGEE for age coverage

## StarGen applicability
Provides independent empirical cross-check for the Milky Way disk metallicity gradient.
The close agreement with HackshawEtAl2024.txt (APOGEE) strengthens the default value
of −0.066 to −0.071 dex/kpc. The 29-element abundance dataset is useful if StarGen
needs to generate detailed stellar abundance fingerprints (not just [Fe/H]) for
comparison with biosignature or spectroscopy simulation outputs.
Cited in GalaxyScienceReferenceCatalog.cs for `metallicity_gradient_dex_per_kpc`.

## Parameters, constraints, and mechanics implications

**Gradient cross-check values:**
- [Fe/H] gradient from C-MetaLL VI: −0.071 ± 0.003 dex/kpc (Cepheid tracers)
- [Fe/H] gradient from APOGEE DR17 (HackshawEtAl2024): −0.066 ± 0.0004 dex/kpc (giants)
- Best combined estimate for StarGen default: −0.068 dex/kpc (midpoint of two recent
  precise measurements); either −0.066 or −0.071 dex/kpc is defensible as default.
- StarGen currently uses −0.066 (APOGEE value); acceptable, within uncertainty.

**Alpha-element ratio gradient (secondary parameter):**
- [Mg/Fe] gradient: slightly positive outward (outer disk is slightly more alpha-enhanced
  than inner disk for young stars), with gradient magnitude ~+0.01 to +0.02 dex/kpc
- This reflects the outside-in enrichment history: outer disk had less Fe-peak
  enrichment from Type Ia SNe relative to alpha-producing Type II SNe
- Implications for StarGen: if generating stellar [Mg/Fe] ratios, use a slight positive
  radial gradient for this element

**Multi-element abundance pattern (for future advanced use):**
- Iron-peak elements (Cr, Ni, Co) track [Fe/H] closely (gradient ≈ same as [Fe/H])
- s-process elements (Y, Ba) show enhanced abundances at intermediate metallicities;
  gradient shallower than [Fe/H] (s-process sources evolved on different timescales)
- These patterns could inform a "stellar chemical fingerprint" generator if StarGen
  eventually wants to generate multi-element stellar abundance profiles

## Conflicts and follow-up work

**Other C-MetaLL papers in the series (context):**
- Ripepi, V., et al. (2021) C-MetaLL I — MNRAS 508, 4047 (HARPS-N spectroscopy of
  47 Cepheids; survey launch). arXiv:2108.07564.
- Trentin, E., et al. (2023) C-MetaLL II — MNRAS 519, 2331 (metal-poor Cepheids).
  arXiv:2209.03792.
- Subsequent papers in the series extend the sample and improve calibrations.

**Comparison papers (gradient measurements):**
- Lemasle, B., et al. (2018) — earlier Cepheid gradient: −0.063 dex/kpc; consistent.
- Genovali, K., et al. (2014) — −0.060 dex/kpc from Cepheids; slightly shallower.
- Donor, J., et al. (2020) APOGEE open clusters: −0.068 dex/kpc; consistent.
- The convergence of all these methods around −0.065 to −0.071 dex/kpc is a strong
  consensus; any value in this range is scientifically defensible for StarGen defaults.

**Note on "cmetall2024" source ID:**
The C-MetaLL survey is a Milky Way disk study using Cepheids — it is about the MW disk
metallicity gradient, NOT about metallicity gradients in external galaxies (despite
the code description "gradient behavior across nearby galaxies"). StarGen's
`metallicity_gradient_dex_per_kpc` parameter references this paper for the MW analog
default, which is then scaled to other galaxy types.

## StarGen mechanics translation

### Metallicity gradient calibration (cross-check reference)
This paper's primary StarGen role is to validate the gradient value used in the galaxy
generator. It does not introduce new parameters beyond what HackshawEtAl2024.txt covers.

**Usage in StarGen:**
- `MetallicityGradientDexPerKpc` default: −0.066 (APOGEE value); this paper confirms it.
- If user selects `CMetaLL2024` as the metallicity source, apply −0.071 dex/kpc.
- For a blended "best-estimate" mode, average the two: −0.0685 dex/kpc.

**Alpha-element enrichment selector (future feature):**
If StarGen adds multi-element stellar abundances, the C-MetaLL VI gradients provide
the radial profile for [Mg/Fe] and [Ca/Fe]:
```
double MgFeRatio(double r_kpc) =>
    MgFeAtSolar + 0.015 * (r_kpc - 8.0);  // slight positive gradient outward
// MgFeAtSolar ≈ 0.05 (thin disk young Cepheids slightly alpha-enhanced vs Sun)
```

**s-process marker (very advanced use):**
[Y/Fe] and [Ba/Fe] at high metallicity drop below solar; at sub-solar metallicity they
rise. This could be used as an age proxy for stellar populations in the StarGen
advanced metadata: older populations in the outer disk have higher [Ba/Fe] relative to
inner disk young stars.

**User lever:** `MetallicityGradientSource` enum: `APOGEE2024` (−0.066) /
`CMetaLL2024` (−0.071) / `Blended` (−0.069) / `Custom`.

**Cross-references:** HackshawEtAl2024.txt (primary APOGEE gradient constraint),
SpitoniEtAl2017.txt (chemical evolution backbone), ForgnEtAl2017.txt (GHZ uses
gradient as input), BlandHawthornGerhard2016.txt (MW disk context).
